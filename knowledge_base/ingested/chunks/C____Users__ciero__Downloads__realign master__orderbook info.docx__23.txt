eat_book first deletes (i.e. “eats up”) as much of the beginning of the ps_pairs: PriceSizePairs data structure as it can (basically matching the input number of shares with an appropri-ate number of shares at the beginning of the ps_pairs: PriceSizePairs input). Note that the returned PriceSizePairs is a separate data structure, ensuring the immutability of the input ps_pairs: PriceSizePairs.
